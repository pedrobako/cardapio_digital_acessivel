# 🍽️ Cardápio Digital Acessível  
### Protótipo de Alta Fidelidade — IHC & UX

Este repositório apresenta o protótipo de alta fidelidade de um **cardápio digital acessível para dispositivos móveis**, desenvolvido como parte da disciplina de **Interação Humano-Computador (IHC) e Experiência do Usuário (UX)**.

## OBJETIVO

O objetivo do projeto é propor uma interface inclusiva, intuitiva e adaptada a diferentes perfis de usuários, garantindo **autonomia de navegação** e **acessibilidade visual**, considerando necessidades reais do dia a dia em restaurantes e aplicativos de delivery.

---

## 🔎 Funcionalidades do protótipo

✔ **Ajuste de tamanho de fonte (A+ / A−)**  
Permite que o usuário aumente a legibilidade dos textos, auxiliando pessoas com baixa visão.
