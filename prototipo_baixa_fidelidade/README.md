**Protótipo de baixa fidelidade**

Nessa etapa, desenvolvemos um protótipo de baixa fidelidade usando Balsamiq para o propor implementações para o projeto de Cardápio Digital Acessível. O objetivo principal deste protótipo foi explorar diferentes ideias de interface e fluxos de interação focados em acessibilidade (alto contraste, opções de leitura em voz, ajuste de tamanho da fonte, filtros por restrições alimentares) e validar como usuários com diferentes necessidades encontrariam e consumiriam informações do cardápio. 

Link do Balsamiq: https://balsamiq.cloud/syk0q7b/psun5s8/rB8DB

**Como foi feito?**

Cada membro do grupo desenvolveu sketches individuais, explorando diferentes possibilidades de layout, navegação e componentes de acessibilidade. Essa etapa permitiu gerar uma grande variedade de ideias sem restrições iniciais.

Em seguida, realizamos uma sessão de comparação e discussão, onde avaliamos os pontos fortes de cada proposta. A partir desse processo coletivo, selecionamos em conjunto os elementos mais claros, acessíveis e eficientes. Esses componentes foram então combinados e refinados para formar um protótipo mais robusto.

Os critérios utilizados para escolher as melhores ideias incluíram:

- Clareza e simplicidade na navegação  
- Facilidade de leitura  
- Efetividade dos recursos de acessibilidade (alto contraste, tamanho de fonte, áudio)  
- Redução de esforço cognitivo para usuários idosos ou com limitações visuais  
- Coerência e consistência entre telas
